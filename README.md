## 🎯 Propósito del Repositorio
Este repositorio es un **Centro de Conocimiento Especializado** dedicado a la investigación, documentación y análisis de incidentes de ciberseguridad. Su objetivo es servir como una base de recursos técnicos para profesionales y estudiantes, proporcionando:

*   **Análisis Críticos**: Desglose de ataques reales como el de *Colonial Pipeline*.
*   **Práctica Defensiva**: Resolución de casos prácticos basados en logs de Windows y Firewalls.
*   **Protocolos Estándar**: Metodologías para la priorización y gestión de alertas en entornos SOC/SIEM.

---

## 📂 Explorar Contenidos

El repositorio está organizado de manera profesional en las siguientes categorías:

### 🔬 [Investigaciones](./investigaciones/)
Contiene análisis de incidentes de alto perfil y estudios sobre amenazas persistentes.

### 📑 [Casos Prácticos](./casos_practicos/)
Guías paso a paso para la identificación de amenazas mediante el análisis de eventos de seguridad.

### 🛡️ [Protocolos](./protocolos/)
Marcos de trabajo diseñados para optimizar la respuesta ante incidentes y la eficiencia operativa.

---

## 🛠️ Tecnologías y Metodologías
*   **Análisis Forense de Logs**: Eventos de Seguridad de Windows (Event 4625).
*   **Seguridad de Red**: Monitoreo de tráfico RDP y HTTPS.
*   **Gestión de Alertas**: SIEM, SOAR y protocolos de priorización.
